# 知乎推荐页净化

一个轻量、无额外权限的 Chrome Manifest V3 扩展，用于精简知乎首页推荐流和部分导航、侧栏入口。

> 非官方第三方扩展，与知乎无隶属、合作或背书关系。

## 功能

- 隐藏明确标记为“广告”或“推广”的推荐卡片。
- 留白与 AI、金融、经济、投资无关的低赞回答。
- 留白与上述主题无关、没有“关注的人赞同/推荐”迹象的高赞文章。
- 隐藏热榜、专栏、圈子、AI Works、故事和直答入口。
- 隐藏右侧“大家都在搜”和“盐言作者平台”。
- 支持知乎动态加载和站内跳转。

## 安装

1. 下载或克隆本仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的项目目录。
6. 刷新知乎页面。

代码更新后，需要先在扩展管理页点击“重新加载”，再刷新知乎。

## 过滤规则

- 广告卡片：原地留白。
- 文章：赞同数不少于 1,000、主题无关且没有关注者背书迹象时留白。
- 回答：赞同数少于 10,000 且主题无关时留白。
- 推荐卡片只在 `https://www.zhihu.com/` 首页处理。
- 导航和侧栏入口在 `https://www.zhihu.com/*` 范围内处理。

“留白”会保留卡片原来的高度和位置，后续内容不会向上补位。

## 隐私

- 不声明 `permissions` 或 `host_permissions`。
- 不主动发起网络请求，不包含统计、遥测或远程代码。
- 只检查知乎页面已经渲染的 DOM，所有判断均在浏览器本地完成。

## 自定义与测试

阈值、主题关键词和入口匹配规则位于 [rules.js](rules.js)。修改后可运行：

```bash
npm test
npm run check
```

知乎会不定期调整页面结构。如果规则失效或发生误过滤，可以提交 [Issue](https://github.com/chiyahoho/zhihu-clean/issues)，并附上已经脱敏的页面信息。
